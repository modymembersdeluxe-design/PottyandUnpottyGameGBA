# Gameplay Tutorial: Potty & Unpotty (GBA)

This guide explains how to play the current prototype version of **Potty & Unpotty**.

---

## 1) Start the game

1. Build or obtain the ROM file:
   - `build/potty_unpotty.gba`
2. Open it in a Game Boy Advance emulator (for example mGBA or VBA-M).
3. On the title screen, press **A** to begin.

---

## 2) Controls

- **D-Pad**: Move or choose directional answers
- **A**: Confirm / action / rhythm tap
- **START**: Pause (during mini-games)

---

## 3) Game flow overview

The game runs in this order:
1. **Title screen**
2. **Hub** (choose a mini-game)
3. Play mini-games to earn wins
4. Reach **5 successful rounds**
5. See **Deluxe Complete** results

---

## 4) Hub selection

At the hub, use:
- **LEFT** → Dash to Potty
- **UP** → Memory Signals
- **RIGHT** → Rhythm Clap

Choose any mode each round.

---

## 5) Mini-game rules

## A) Dash to Potty
Goal: reach the goal area before timer ends.

- Move with D-Pad.
- Touch yellow bonus blocks for extra score.
- Avoid cyan hazard blocks to prevent score loss/combo reset.
- Reach the goal to count a successful round.

Tips:
- Stay centered to react faster to hazards.
- Grab bonuses only when the route is safe.

## B) Memory Signals
Goal: repeat the displayed D-Pad sequence.

- A number sequence is shown.
- Enter inputs using D-Pad directions.
- Correct full sequence = success.
- Wrong input or timeout = fail.

Tips:
- Repeat the sequence out loud before entering.
- Keep a steady rhythm instead of rushing.

## C) Rhythm Clap
Goal: press **A** when moving marker lines up with center zone.

- A marker sweeps across a timing bar.
- Press A close to the center for best scoring.
- Build combo with good timing.
- Finish required beats before timer ends.

Tips:
- Watch movement pattern for one loop first.
- Tap slightly before center if your emulator has input latency.

---

## 6) Score, stars, and combo

- **Score** increases from bonuses and successful actions.
- **Stars** increase on successful rounds.
- **Combo** grows with consecutive good actions and boosts points.
- Mistakes can reduce score or combo.

---

## 7) Win condition

- Achieve **5 successful rounds** total.
- The game shows a **Deluxe Complete** results screen.
- Press **A** to restart from title.

---

## 8) Beginner progression plan

If you're new, try this order:
1. Start with **Dash** to learn movement.
2. Use **Memory** to build consistent clears.
3. Use **Rhythm** once you are comfortable with timing.

This rotation makes it easier to reach 5 wins quickly.

---

## 9) Troubleshooting while playing

### Game feels too fast
- Check emulator speed is set to 100%.
- Disable fast-forward.

### Inputs feel delayed
- Enable low-latency or run-ahead options in emulator settings.
- Use keyboard/gamepad polling settings recommended by emulator.

### Screen text looks odd
- The prototype uses simple debug-style text rendering.
- This is expected and can be replaced with a tile font later.
